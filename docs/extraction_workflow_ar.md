# سير عمل استخراج كتالوج Nissan Patrol Y60 EPC

## المرحلة 1: استلام المصادر

1. وضع ملفات EPC الرسمية داخل `sources/official_epc/`.
2. تعبئة `data/source_intake_manifest.csv`.
3. تحديد سنة الإنتاج والسوق والفئة والمحرك وناقل الحركة لكل مصدر.

## المرحلة 2: التحقق الأولي

يتم فحص كل مصدر للتأكد من وجود:

- رقم لوحة EPC الأصلي.
- عنوان اللوحة الأصلي.
- المخطط التفجيري الكامل.
- أرقام النداء والمرجع.
- أرقام قطع نيسان.
- جدول القطع المرتبط بالمخطط.
- نطاقات VIN أو تاريخ الإنتاج عند توفرها.
- السوق والمحرك وناقل الحركة والفئة.

## المرحلة 3: الاستخراج

يتم استخراج كل لوحة ككيان مستقل:

- Plate
- Diagram
- Callouts
- Parts table
- Applicability
- Supersession data
- Cross references

كل قطعة موضحة في الرسم يجب أن تظهر في جدول القطع.

## المرحلة 4: الترجمة

تتم ترجمة الحقول النصية إلى العربية الفنية المستخدمة في ورش الخليج والسعودية، مع عدم ترجمة:

- أرقام القطع.
- أرقام VIN.
- أكواد المحركات.
- أكواد القير.
- أكواد المحاور.
- الاختصارات الرسمية.

## المرحلة 5: ضبط الجودة

يتم رفض اعتبار الكتالوج مكتملًا إذا وجدت أي مشكلة من التالية:

- لوحة EPC مفقودة.
- مخطط مفقود.
- رقم قطعة مفقود.
- رقم نداء غير مرتبط بقطعة.
- قطعة في الجدول غير ظاهرة في المخطط.
- ترجمة عربية ناقصة.
- نطاق VIN أو تاريخ إنتاج غير موثق.
- رقم بديل أو ملغى غير موثق.

## المرحلة 6: الإخراج النهائي

بعد اكتمال المصادر والتحقق، يتم توليد:

- Master PDF
- DOCX
- Excel
- CSV
- SQLite
- JSON
- Markdown
- فهارس حسب السنة والمحرك والسوق والنظام ورقم القطعة والاسم العربي والإنجليزي

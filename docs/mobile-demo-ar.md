# صفحة محاكاة بطل الدروب للجوال

تم إنشاء صفحة ويب خفيفة لمحاكاة شكل تطبيق **بطل الدروب** على الجوال وطريقة تصفحه.

## الملفات

- `mobile-demo.html`
- `mobile-demo.css`
- `mobile-demo.js`

## ماذا تعرض الصفحة؟

- شكل هاتف يحاكي التطبيق.
- الصفحة الرئيسية.
- البحث عن القطع.
- قائمة نتائج القطع.
- صفحة تفاصيل القطعة.
- محاكاة الدفع الرمزي لفتح رقم القطعة.
- محاكاة فتح الكتالوجات المحمية.
- شرح مختصر لطريقة التصفح.

## رابط التشغيل المحلي

على نفس جهاز الماك:

```text
http://127.0.0.1:5015/mobile-demo.html
```

على الجوال إذا كان متصلًا بنفس شبكة الماك:

```text
http://172.20.10.4:5015/mobile-demo.html
```

## أمر التشغيل الآمن

يتم تشغيل الصفحة من مجلد مؤقت يحتوي ملفات المحاكاة فقط:

```bash
python3 -m http.server 5015 --bind 0.0.0.0
```

المجلد المؤقت المستخدم:

```text
/tmp/batal-mobile-demo
```

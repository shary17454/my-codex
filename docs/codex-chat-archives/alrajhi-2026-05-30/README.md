# أرشيف دردشة قضية مصرف الراجحي

هذا المجلد يجمع مخرجات الدردشة والعمل المنجز بخصوص قضية مصرف الراجحي، بما في ذلك:

- تحليل قانوني أولي شامل.
- مراجعة نقدية لصحيفة الدعوى.
- صحيفة دعوى منقحة.
- جدول أدلة ومطالبات.
- نص مستخرج من صحيفة الدعوى الأصلية.
- صور مجمعة للأدلة المدمجة داخل ملف الدعوى.
- نسخة عمل من صحيفة الدعوى الأصلية.

## تنبيه خصوصية

هذا الأرشيف يحتوي بيانات شخصية وحساسة، منها رقم الهوية، رقم الحساب، الآيبان، رقم الجوال، البريد الإلكتروني، تفاصيل دعوى، وصور مستندات. لا يوصى برفعه إلى مستودع عام. إن كان مستودع GitHub عاماً، فيجب إما جعله خاصاً أو حذف/تنقيح البيانات الحساسة قبل الرفع.

## هيكل الملفات

- `legal_case_alrajhi/`: ملفات التحليل القانوني والصحيفة المنقحة ونسخة العمل.
- `evidence_extracts/`: نصوص وصور مستخرجة من ملف صحيفة الدعوى.
- `CHAT_SUMMARY_AR.md`: ملخص تفصيلي لما تم في الدردشة.
- `FILES_INDEX.md`: فهرس الملفات والغرض منها.

## ملاحظة عن اكتمال الدردشة

لا يوجد في بيئة العمل تصدير حرفي تلقائي لكل رسائل واجهة الدردشة. لذلك تم حفظ ملخص تفصيلي ومخرجات العمل والملفات التي نشأت عن الدردشة. إذا توفر تصدير رسمي من واجهة Codex أو المتصفح، يمكن إضافته لاحقاً إلى هذا المجلد.

# خطة تنفيذ منصة رواية (MVP المرحلة الأولى)

## 1) تحليل المتطلبات
- منصة تراث عربية متعددة المجالات مع فئات محتوى كثيرة.
- دعم مستخدمين، مساهمين، مراجعين، محررين، إداريين.
- نظام مراجعة ومواصفات تحقق للمحتوى ومصادر.

## 2) البنية التقنية
- Monorepo: apps/api, apps/web, apps/admin, apps/mobile + packages.
- NestJS + Prisma + PostgreSQL + Redis + JWT.
- Next.js للويب والإدارة.
- Flutter للأندرويد/IOS.

## 3) MVP المرحلة الأولى
- تسجيل/دخول، إدارة المستخدم وصلاحيات RBAC.
- صفحات المحتوى الأساسية (الشعر، القصص، الكتب، الخيل، الإبل، الصقارة، كلاب الصيد).
- البحث الأساسي.
- المفضلة، التعليقات، الإبلاغات، الأسئلة.

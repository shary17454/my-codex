# سياق الدردشة ومخرجاتها

## الطلب الأصلي

طلب المستخدم إنشاء نموذج أولي MVP لتطبيق باسم مؤقت "ركّبها" يساعد المستخدم على معرفة طريقة تركيب واستخدام المنتجات خطوة بخطوة.

كانت الفكرة الأساسية تشمل منتجات مثل:

- شنط السيارات.
- أنوار السيارات.
- الإكسسوارات.
- الأدوات المنزلية.
- أدوات التخييم.
- الأجهزة البسيطة.
- المنتجات التي تحتاج كتيبات أو شرح تركيب.

في البداية كان المطلوب تطبيق iPhone باستخدام SwiftUI، باللغة العربية بالكامل، مع دعم RTL، وبيانات تجريبية Mock Data، وبدون Backend أو دفع أو إعلانات حقيقية.

## التغيير إلى نسخة متصفح

أوقف المستخدم مسار iOS وطلب صراحة:

> خله متصفح لاتسوي ios

بناءً على ذلك تم تحويل العمل إلى نموذج ويب ثابت يعمل في المتصفح، مناسب للفتح من الجوال، بدون Backend وبدون مكتبات خارجية.

## الشاشات المطلوبة والمنفذة

تم تنفيذ تجربة MVP عربية RTL تشمل:

- شاشة رئيسية باسم "ركّبها".
- وصف الفكرة: "اعرف طريقة تركيب واستخدام أي منتج خطوة بخطوة".
- زر "صوّر المنتج" كواجهة Mock.
- زر "ابحث يدويًا".
- أقسام سريعة: سيارات، أدوات، أجهزة، تخييم، أثاث.
- شاشة بحث بقائمة منتجات تجريبية.
- شاشة تفاصيل المنتج.
- شاشة خطوات التركيب خطوة بخطوة مع شريط تقدم.
- شاشة مساعدة ذكية Mock Chat بدون ذكاء اصطناعي حقيقي.
- شاشة المفضلة باستخدام `localStorage`.
- شاشة الحساب مع حالة مجاني وبطاقة Premium مستقبلية غير مفعلة.

## البيانات التجريبية

تمت إضافة ستة منتجات Mock:

1. تركيب شنطة سقف للسيارة.
2. تركيب لمبة LED عالية للسيارة.
3. تركيب حامل جوال.
4. استخدام منفاخ هواء محمول.
5. تركيب خيمة تخييم.
6. تركيب رف جداري بسيط.

كل منتج يحتوي على:

- الاسم.
- التصنيف.
- مستوى الصعوبة.
- الوقت المتوقع.
- وصف مختصر.
- الأدوات المطلوبة.
- التحذيرات.
- خطوات التركيب.

## قرارات التنفيذ

- تم إنشاء تطبيق ويب ثابت بثلاثة ملفات أساسية: `index.html`, `styles.css`, `app.js`.
- تم دعم اللغة العربية واتجاه RTL عبر `lang="ar"` و `dir="rtl"`.
- تم استخدام بيانات Mock داخل `app.js`.
- تم حفظ المفضلة محليًا عبر `localStorage`.
- لم تتم إضافة Backend.
- لم تتم إضافة تسجيل دخول حقيقي.
- لم تتم إضافة دفع حقيقي.
- لم تتم إضافة إعلانات حقيقية.
- لم تتم إضافة خدمات خارجية مدفوعة.

## تحسين التصميم

بعد تجربة النسخة الأولى، قال المستخدم إن التصميم عادي وطلب تصميمًا عصريًا وفخمًا.

تم تحديث الواجهة لتشمل:

- Hero section أكثر فخامة.
- ألوان داكنة وفخمة مع لمسات ذهبية وخضراء.
- بطاقات شفافة بنمط glass.
- شريط تنقل سفلي أنظف.
- بطاقات منتجات محسنة.
- شاشة تفاصيل أقوى بصريًا.
- تحسين تجربة العرض على الجوال.

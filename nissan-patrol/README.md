# ملفات نيسان باترول

حزمة مختصرة ومنظمة لملفات مرجعية عن نيسان باترول، مناسبة للحفظ أو التوسعة لاحقاً داخل المستودع.

## المحتويات

- `overview.md`: ملخص عربي سريع عن السيارة والأجيال والاستخدامات.
- `specs-2026.json`: بيانات منظمة قابلة للقراءة آلياً عن مواصفات باترول الحديثة حسب مصادر نيسان الرسمية للشرق الأوسط.
- `maintenance-checklist.md`: قائمة فحص وصيانة دورية مبسطة.

## ملاحظات

- الأرقام تختلف حسب السوق والفئة وسنة الموديل.
- الملف `specs-2026.json` يركز على باترول الحديثة المتوفرة في أسواق الشرق الأوسط، ويجب مراجعته قبل استخدامه كمرجع بيع أو تسعير رسمي.

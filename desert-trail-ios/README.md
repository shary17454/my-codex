# درب الصحراء - iOS

هذا المجلد يحتوي مشروع تطبيق درب الصحراء لنظام iOS.

## فتح المشروع

- افتح الملف:
  `DesertTrail/DesertTrail.xcodeproj`
- Bundle ID الحالي:
  `com.codex.DesertTrail`
- النسخة الحالية:
  `1.0`
- آخر رقم بناء محلي:
  `22`

## ملاحظات مهمة

- تم استبعاد ملفات البناء المؤقتة مثل `DerivedData` و`build` وملفات `.ipa` و`.xcarchive`.
- ملفات مفاتيح App Store Connect الخاصة مثل `AuthKey_*.p8` غير مرفوعة للمستودع.
- يمكن تعديل ملفات Swift وواجهات التطبيق من GitHub، لكن بناء ورفع تطبيق iOS يحتاج Xcode أو خدمة CI تدعم macOS مثل Xcode Cloud أو GitHub Actions على macOS.

## آخر ما تم إضافته

- قسم دليل الحياة الفطرية.
- قاعدة بيانات أولية للحيوانات والزواحف والحشرات.
- خريطة انتشار تقريبية وتنبيهات حسب الموقع.
- دليل النباتات والمحميات والمناطق المقيدة.
- دليل السلامة البرية وآثار الحيوانات ومواسم النشاط.
- دليل الفلك والجيولوجيا.

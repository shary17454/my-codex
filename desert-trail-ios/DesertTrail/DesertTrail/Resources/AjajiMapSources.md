# Ajaji Map Sources

Current bundled PDF files:

- `AjajiSaudi.pdf`
- `AjajiRiyadhRegion.pdf`
- `AjajiMarkedPlans.pdf`

These PDFs were generated from the user-provided Ajaji map images during development because no accessible official PDF download URL was found from the public web search or from `ajajimaps.com` at implementation time.

To replace them with official high-resolution PDFs, either:

- Import the official PDF in the app using the map screen's `Import Official PDF` action.
- Download a direct official PDF URL from the app using `Manage PDF Source`.
- Keep the same file names and replace the bundled PDFs in this folder, then rebuild the app.

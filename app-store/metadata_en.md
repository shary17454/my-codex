## Description
Batal Al-Droob is a structured reference for Nissan Patrol Y60 parts. It helps users search by part number, name, category, catalog source, and audit status.

The app uses an audited database extracted from PDF catalogs and shows useful details such as appearance years, engines, application date ranges, source count, confidence score, and catalog evidence.

Features:
- Search by part number, name, or category.
- Arabic and English interface.
- Categories for engine, cooling, electrical, body, brake, suspension, fuel, and more.
- Audit status and confidence score for records.
- Wishlist for saved parts.
- Useful for Nissan Patrol Y60 owners, maintenance, and restoration projects.

Note: This app is an informational reference. Always verify part numbers before purchase or installation.

## الوصف العربي

بطل الدروب هو مرجع منظم لقطع نيسان باترول Y60، يساعدك على البحث عن رقم القطعة، اسمها، توافقها، مصدرها في الكتالوج، وحالة تدقيق البيانات.

يعتمد التطبيق على قاعدة بيانات مدققة من كتالوجات PDF، ويعرض للمستخدم معلومات مهمة مثل سنوات الظهور، المحركات، تواريخ التطبيق، عدد المصادر، وأدلة من صفحات الكتالوج.

المزايا:
- البحث برقم القطعة أو الاسم أو القسم.
- دعم العربية والإنجليزية.
- تصنيف القطع حسب الأقسام مثل المحرك، التبريد، الكهرباء، الهيكل، الفرامل، التعليق، والوقود.
- عرض حالة التدقيق ودرجة الثقة.
- حفظ القطع في قائمة الرغبات.
- مناسب لملاك ومهتمي نيسان باترول Y60 ومشاريع الصيانة والترميم.

ملاحظة: التطبيق مرجع معلوماتي، ويجب التأكد من رقم القطعة قبل الشراء أو التركيب.

## Review Notes

App name: Batal Al-Droob / بطل الدروب

This app is an informational reference catalog for Nissan Patrol Y60 parts. It contains an offline bundled catalog database extracted from parts PDFs and audited into structured records.

No login is required. No payment is required in this version. No user-generated content is submitted in this version. No account credentials are needed for review.

Main test flow:
1. Open the app.
2. Search for a part number such as `63850-05J91`.
3. Open a result.
4. Review fitment years, catalog evidence, audit status, and confidence score.
5. Switch language between Arabic and English using the top button.

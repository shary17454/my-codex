# راح تفهم

مشروع تطبيق iOS باسم **راح تفهم**، منصة عربية تساعد المستخدم على المقارنة بين المنتجات والخدمات والاختيارات المختلفة، مع تصويتات وتعليقات وبيانات جاهزة داخل التطبيق.

## محتويات المستودع

- `StudyVaultApp/StudyVault.xcodeproj`: مشروع Xcode.
- `StudyVaultApp/StudyVault`: كود SwiftUI وملفات التطبيق.
- `StudyVaultApp/StudyVault/ProductKnowledge.json`: قاعدة بيانات المنتجات والمقارنات.
- `StudyVaultApp/StudyVault/SeedQuestions.json`: أسئلة ومقارنات جاهزة.
- `StudyVaultApp/AppStore`: وصف ولقطات شاشة وملفات تجهيز App Store.
- `StudyVaultApp/scripts`: أدوات مساعدة للرفع والتجهيز.

## ملاحظات مهمة

- لم يتم رفع ملفات التوقيع أو مفاتيح Apple أو ملفات `.ipa`.
- لم يتم رفع مخرجات البناء `build` أو الأرشيفات لأنها كبيرة ويمكن توليدها من جديد عبر Xcode.
- المشروع الحالي يستخدم Bundle ID: `com.shary17454.esal`.
- الإصدار الحالي في المشروع: `1.2`، ورقم البناء الأخير: `19`.

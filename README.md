# my-codex

مستودع أرشيف وتجارب Codex قديمة. لم يعد هذا المستودع مصدرًا نهائيًا لأي تطبيق من قائمة التطبيقات المعتمدة.

## حالة التطبيقات

تم تفريغ نسخ التطبيقات النهائية من هذا المستودع لتجنب التكرار. المستودعات النهائية هي:

| التطبيق | المستودع النهائي | ملاحظات |
| --- | --- | --- |
| بطل الدروب | `batal-aldroob` | يحتوي تطبيق iOS ومصادر الويب والبيانات القديمة ذات الصلة. |
| وش الرأي | `wash-alray` | يدمج `StudyVaultApp` و`اسأل الناس` تحت الاسم النهائي وش الرأي. |
| خرايم | `kharaim` | يدمج `Kharayem` وما يخص مدّل/درب الصحراء وRafiq. |
| كمهوبه | `kamhooba-ios` | يحتوي مشروع كمهوبه الأصلي ونسخ Flutter القديمة ذات الصلة. |
| Safari Y60 Parts | `safari-y60-parts` | يحتوي مشروع SwiftUI ومواد Patrol/Safari Y60 القديمة. |
| كتلوجات أجيال وموديلات باترول | `ktalojat-ajyal-modilat-patrol-shamla-bdf` | يحتوي كتالوجات باترول وملفات PDF وقواعد البيانات والمصادر التي كانت متبقية هنا. |

## ما يبقى هنا

يبقى هذا المستودع للاحتفاظ بمخرجات ووثائق وتجارب ليست مصدرًا نهائيًا لتطبيق مستقل ضمن القائمة المعتمدة، مثل:

- وثائق ومخرجات SAIP.
- سجلات ومخرجات محادثات أو تجارب عامة.
- ملفات أرشيفية غير مرتبطة مباشرة بمستودع تطبيق نهائي.

كتالوجات باترول لم تعد محفوظة هنا كمصدر نهائي. تم نقلها إلى مستودع `ktalojat-ajyal-modilat-patrol-shamla-bdf`.

## ملاحظات تشغيل وبناء

لا يوجد تطبيق نهائي يُبنى من هذا المستودع بعد التفريغ. شغّل أو ابنِ كل تطبيق من مستودعه النهائي.

## ملاحظات نشر

لا يُستخدم هذا المستودع لـ Railway أو Xcode Cloud أو App Store Connect بعد التفريغ. أي إعدادات نشر تخص التطبيقات موجودة أو موثقة داخل المستودع النهائي لذلك التطبيق.

## سياسة الأسرار

لا تضع ملفات `.env` الحقيقية أو مفاتيح API أو شهادات التوقيع داخل هذا المستودع. استخدم ملفات أمثلة فقط مثل `.env.example` عند الحاجة.

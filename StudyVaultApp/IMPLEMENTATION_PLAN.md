# خطة تنفيذ وش الرأي

## ملخص المعمارية

- نوع المشروع: تطبيق iOS/iPadOS باستخدام SwiftUI.
- نقطة الدخول: `StudyVault/StudyVaultApp.swift`.
- الواجهة الرئيسية: `StudyVault/ContentView.swift`.
- النماذج الحالية: `StudyVault/AskModels.swift`.
- البيانات الحالية: ملفات JSON محلية مثل `SeedQuestions.json` و`ProductKnowledge.json`.
- إدارة الحالة الحالية: SwiftUI مع `@StateObject` للحساب، و`@Observable`/Observation في `HomeViewModel` و`CreateComparisonViewModel` لإدارة الصفحة الرئيسية، البحث، التصويت، الحفظ، وإنشاء المقارنات.
- التنقل الحالي: `TabView` مع `NavigationStack` و`sheet`.
- قاعدة البيانات/Backend: لا يوجد Backend فعلي حاليًا. التطبيق يعمل محليًا ببيانات داخلية.
- المصادقة: يوجد دعم أولي لـ Sign in with Apple داخل `UserSession`، لكنه ليس مربوطًا بخادم.
- رفع الصور: لا يوجد رفع صور فعلي حاليًا لأن المشروع لا يحتوي Backend.

## الملفات الحالية المهمة

- `StudyVault/ContentView.swift`: جميع الشاشات الأساسية وتجربة المستخدم.
- `StudyVault/AskModels.swift`: النماذج، بيانات العرض، ومحرك المقارنة المحلي.
- `StudyVault/ViewModels.swift`: طبقة MVVM للصفحة الرئيسية والبحث والتصويت والحفظ وإنشاء المقارنات.
- `StudyVault/SeedQuestions.json`: الأسئلة الأولية.
- `StudyVault/ProductKnowledge.json`: قاعدة معرفة محلية.
- `StudyVault/Info.plist`: إعدادات التطبيق.
- `StudyVault.xcodeproj/project.pbxproj`: إعدادات البناء والنسخة.

## الملفات التي سيتم تعديلها

- `StudyVault/AskModels.swift`: إضافة نماذج MVP، بروتوكولات الخدمات، خدمات التحقق، الحفظ، المسودات، التصويت، الملخص، والبحث.
- `StudyVault/ContentView.swift`: ربط الحفظ، المسودات، التحقق، حالات الواجهة، وتحسين إنشاء المقارنة والتفاصيل.
- `StudyVault/ViewModels.swift`: فصل منطق الصفحة الرئيسية وإنشاء المقارنة والبحث والتصويت والحفظ عن الواجهة.
- `README.md`: تحديث طريقة التشغيل وحدود النسخة المحلية.

## الملفات الجديدة المطلوبة

- `IMPLEMENTATION_PLAN.md`: خطة التنفيذ الحالية.
- `IMPLEMENTATION_REPORT.md`: تقرير التنفيذ والتحقق بعد الانتهاء.

## خطة التنفيذ

1. توثيق المعمارية الحالية والحدود.
2. إضافة نماذج المقارنة المطلوبة بدون كسر النماذج الحالية.
3. إضافة طبقة خدمات محلية Protocol + Local implementation.
4. إضافة ViewModel ملاحظ بـObservation للصفحة الرئيسية.
5. إضافة ViewModel مستقل لإنشاء المقارنات مع تحقق واضح.
6. حفظ واستعادة المسودات محليًا.
7. حفظ المقارنات محليًا.
8. تحسين حساب نسب التصويت وملخص القرار.
9. تحسين شاشة إنشاء المقارنة برسائل خطأ عربية ومنع التكرار.
10. تحسين شاشة التفاصيل بالحفظ والمشاركة وسبب التصويت.
11. تحديث README.
12. تشغيل Build وإصلاح أخطاء Compilation.
13. إنشاء تقرير نهائي.

## المخاطر والتعارضات المحتملة

- لا يوجد Backend، لذلك التصويت بين عدة مستخدمين غير متزامن فعليًا حاليًا.
- لا يوجد رفع صور حقيقي لأن ذلك يحتاج خدمة تخزين وBackend.
- إضافة Test Target كامل يدويًا داخل مشروع Xcode قد تكون مخاطرة على ملف المشروع، لذلك سيتم التركيز أولًا على Build واستقرار التطبيق.
- المشروع يحتوي ملفات مكررة تحمل suffix `2`، ولن يتم لمسها لتجنب كسر إعدادات Xcode.

## ميزات تتطلب Backend أو إعدادًا خارجيًا

- التصويت الحقيقي بين المستخدمين.
- منع التصويت المكرر عبر الحسابات والأجهزة.
- رفع الصور والتحقق منها.
- التعليقات المتزامنة والردود.
- الإشعارات الفورية.
- نظام السمعة الحقيقي.
- الإبلاغ والإشراف من لوحة إدارة.
- Deep Links عامة وUniversal Links.

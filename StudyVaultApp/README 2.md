# وش الراي iOS

تطبيق iOS عربي باسم "وش الراي" لطرح أسئلة المقارنة بين المنتجات والخدمات، ثم استقبال تصويت وتعليقات من أشخاص مهتمين بنفس المجال.

Bundle ID الحالي: `com.shary17454.esal`

## المحتوى

- مشروع Xcode: `StudyVault.xcodeproj`
- كود التطبيق: `StudyVault/`
- قاعدة بيانات الأسئلة الأولية: `StudyVault/SeedQuestions.json`
- بيانات App Store: `AppStore/`
- سكربت توليد الأيقونة: `Tools/GenerateIcon.swift`

## الوظائف

- طرح سؤال مقارنة جديد.
- دعم المقارنة بين خيارين وحتى 10 خيارات.
- تصويت مباشر على الخيارات.
- عرض نسب التصويت والاختيار الأعلى.
- تعليقات على كل سؤال مع سبب التصويت.
- ملخص قرار ذكي يربط بين التصويت، وزن الخبرة، ونسبة الندم.
- مؤشرات ثقة لكل خيار: أصوات موثقة، آراء خبراء، رضا، ندم، وإعادة شراء.
- صفحة معرفة حية لكل عنصر تعرض نقاط القرار والرضا والملاحظات.
- لوحة ميزات متقدمة للتوصية الشخصية، توثيق التجربة، القرار الجماعي، والمقارنات السريعة.
- تصفية الأسئلة حسب المجال: جوالات، سيارات، مطاعم، لابتوبات، ألعاب، سفر، وغيرها.
- بحث باسم المنتج أو السؤال.
- دعم RTL عربي.
- تسجيل دخول اختياري بـ Apple مع اسم مستعار محفوظ محليًا.
- نموذج أولي يعمل محليًا بدون خادم.

## قاعدة البيانات

التطبيق يقرأ أسئلة أولية وقاعدة معرفة من ملفات JSON داخل التطبيق. البيانات تشمل أسماء منتجات وخدمات حقيقية في مجالات الجوالات والسيارات والمطاعم واللابتوبات والألعاب والسفر، لكنها تبدأ بدون أي تصويتات أو تعليقات مصطنعة. أرقام التصويت والتعليقات تُنشأ فقط من استخدام التطبيق، بينما مؤشرات الثقة والندم والرضا في النسخة الحالية مؤشرات محلية مشتقة لعرض تجربة المنتج إلى أن يتم ربطها بخادم حقيقي.

## البناء محليًا

للبناء على Simulator:

```bash
xcodebuild -project StudyVault.xcodeproj -target StudyVault -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

للأرشفة والرفع إلى App Store:

1. افتح `StudyVault.xcodeproj` في Xcode.
2. سجّل دخولك بحساب Apple Developer من Xcode إذا لم تكن مسجلًا.
3. اختر Apple Developer Team عندما يطلب Xcode ذلك.
4. اختر `Any iOS Device`.
5. نفّذ `Product > Archive`.
6. ارفع من Organizer إلى App Store Connect.

إذا رفضت Apple المعرف `com.shary17454.esal` لأنه غير متاح، غيّره فقط إلى معرف آخر تملكه مثل `com.shary17454.esalapp`.

## ملاحظة عن بيئة البناء الحالية

تم التحقق من أن كود Swift يبني بنجاح عبر:

```bash
xcodebuild -project StudyVault.xcodeproj -scheme StudyVault -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

إذا ظهرت على جهاز آخر رسائل مرتبطة بالـ Simulator runtime أو iOS platform، فهي إعدادات Xcode محلية وليست خطأ في منطق التطبيق. نزّل المكونات المطلوبة من:

```text
Xcode > Settings > Components
```

# حالة ميزات وش الرأي

## منفذ داخل التطبيق

- ملخص قرار ذكي محلي يعرض المتصدر، الثقة، الفارق، وحالة الحسم.
- تحليل أسباب التصويت حسب كل خيار.
- استخراج إيجابيات وسلبيات من أسباب التصويت.
- جدول مواصفات إرشادي حسب تصنيف المقارنة.
- مقارنات مشابهة لتقليل تكرار الأسئلة.
- أسباب جاهزة للتصويت حسب التصنيف.
- شارة "مجرّب فعليًا" داخل سبب التصويت.
- حفظ المقارنات محليًا.
- حفظ مسودة المقارنة محليًا.
- قوالب بدء سريعة لإنشاء مقارنة.
- مدة تصويت اختيارية داخل المسودة.
- فرز المقارنات حسب الأحدث، الأكثر تصويتًا، الأكثر نقاشًا، أوضح قرارًا، والنتائج المتقاربة.
- مركز إحصائيات في الرئيسية.
- لوحة شخصية تعرض أرقام المقارنات والأصوات والأسباب والمحفوظات.
- اختيار اهتمامات المستخدم محليًا.
- مشاركة نص المقارنة عبر ShareLink.
- دعم العربية واتجاه RTL في الواجهات الحالية.

## يتطلب Backend أو إعدادًا خارج التطبيق

- تصويت جماعي حقيقي بين عدة مستخدمين مع منع التكرار من الخادم.
- تقييم جودة التصويت ووزن المستخدمين بصورة غير قابلة للتلاعب.
- التعليقات المتقدمة والردود والإشراف المركزي.
- الإبلاغ والحظر والفلترة النهائية على الخادم.
- إشعارات Push عند تغير النتيجة أو وصول تعليق.
- حسابات موثقة للشركات أو الخبراء.
- نظام سمعة موثوق غير قابل للتلاعب من العميل.
- روابط عميقة/Universal Links تعمل خارج الجهاز.
- تسويق بالعمولة وأسعار وعروض مباشرة من متاجر.
- تقارير مدفوعة للشركات.
- مزامنة المقارنات والمحفوظات بين الأجهزة.

## يتطلب Targets أو Capabilities منفصلة

- Widget.
- Apple Watch.
- Siri Shortcuts.
- QR/PDF/CSV export المتقدم إذا كان مطلوبًا كملفات مشاركة كاملة.

## ملاحظة تنفيذ

النسخة الحالية تعزز تجربة القرار داخل تطبيق iOS الموجود دون تغيير Bundle ID أو Signing أو إضافة اعتماديات خارجية. أي ميزة تتطلب ثقة بين المستخدمين أو مزامنة أو إشعارًا حقيقيًا يجب تنفيذها بخدمة Backend قبل اعتبارها إنتاجية.

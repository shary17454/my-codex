# حالة ميزات وش الرأي

## منفذ داخل التطبيق

- ملخص قرار ذكي محلي يعرض المتصدر، الثقة، الفارق، وحالة الحسم.
- تحليل أسباب التصويت حسب كل خيار.
- استخراج إيجابيات وسلبيات من أسباب التصويت.
- جدول مواصفات إرشادي حسب تصنيف المقارنة.
- مقارنات مشابهة لتقليل تكرار الأسئلة.
- أسباب جاهزة للتصويت حسب التصنيف.
- شارة "مجرّب فعليًا" داخل سبب التصويت.
- حفظ المقارنات محليًا.
- حفظ مسودة المقارنة محليًا.
- قوالب بدء سريعة لإنشاء مقارنة.
- مدة تصويت اختيارية داخل المسودة.
- فرز المقارنات حسب الأحدث، الأكثر تصويتًا، الأكثر نقاشًا، أوضح قرارًا، والنتائج المتقاربة.
- مركز إحصائيات في الرئيسية.
- لوحة شخصية تعرض أرقام المقارنات والأصوات والأسباب والمحفوظات.
- اختيار اهتمامات المستخدم محليًا.
- مشاركة نص المقارنة عبر ShareLink.
- رابط عميق محلي بصيغة `weshalray://comparison/{id}`.
- QR Code لكل مقارنة يشارك الرابط العميق.
- تصدير نتائج المقارنة بصيغة CSV نصية عبر المشاركة.
- تذكير محلي للمقارنة باستخدام Local Notifications بعد طلب الإذن من المستخدم.
- نموذج إبلاغ محلي يحفظ البلاغات على الجهاز.
- Backend تطوير محلي عبر REST API للمقارنات والتصويت والتعليقات والبلاغات.
- إعداد Backend اختياري داخل التطبيق لربط الخادم وجلب/إرسال المقارنات.
- Dockerfile ومخطط PostgreSQL مرجعي للانتقال إلى إنتاج.
- دعم العربية واتجاه RTL في الواجهات الحالية.

## يتطلب Backend أو إعدادًا خارج التطبيق

- تشغيل Backend الإنتاج على استضافة فعلية وربطه بقاعدة بيانات دائمة ومصادقة.
- تصويت جماعي إنتاجي بين عدة مستخدمين مع منع التكرار من الخادم.
- تقييم جودة التصويت ووزن المستخدمين بصورة غير قابلة للتلاعب.
- التعليقات المتقدمة والردود والإشراف المركزي.
- إرسال البلاغات لفريق إشراف فعلي والحظر والفلترة النهائية على الخادم.
- إشعارات Push عند تغير النتيجة أو وصول تعليق. الموجود الآن تذكير محلي فقط.
- حسابات موثقة للشركات أو الخبراء.
- نظام سمعة موثوق غير قابل للتلاعب من العميل.
- Universal Links تعمل خارج الجهاز ومع روابط ويب عامة. الموجود الآن URL Scheme محلي.
- تسويق بالعمولة وأسعار وعروض مباشرة من متاجر.
- تقارير مدفوعة للشركات.
- مزامنة المقارنات والمحفوظات بين الأجهزة.

## يتطلب Targets أو Capabilities منفصلة

- Widget.
- Apple Watch.
- Siri Shortcuts.
- PDF/Excel export المتقدم إذا كان مطلوبًا كملفات مشاركة كاملة. CSV الحالي نص قابل للمشاركة.

## ملاحظة تنفيذ

النسخة الحالية تعزز تجربة القرار داخل تطبيق iOS الموجود دون تغيير Bundle ID أو Signing أو إضافة اعتماديات خارجية. تمت إضافة Backend تطوير محلي في `StudyVaultApp/backend`، لكنه يحتاج تحويلًا لإنتاج بقاعدة بيانات ومصادقة وإشراف قبل اعتباره منصة عامة.

# تقرير تنفيذ تحديث MVP لتطبيق وش الرأي

## ملخص المعمارية

المشروع الحالي تطبيق iOS وiPadOS مبني بـ SwiftUI داخل مشروع Xcode باسم `StudyVault`. الواجهة الرئيسية موجودة في `StudyVault/ContentView.swift`، والنماذج والمنطق المحلي والبيانات التجريبية المنظمة موجودة في `StudyVault/AskModels.swift`، وتمت إضافة طبقة MVVM في `StudyVault/ViewModels.swift` باستخدام Observation لإدارة الصفحة الرئيسية، البحث، التصويت، الحفظ، وإنشاء المقارنات.

التطبيق يعتمد حاليًا على بيانات محلية وملفات JSON و`UserDefaults`، ولا يحتوي على Backend فعلي للتصويت الجماعي أو رفع الصور أو مزامنة الحسابات. توجد جلسة مستخدم محلية مع دعم Apple Sign In على مستوى الواجهة، لكنها لا تمثل مصادقة خادم كاملة.

## الملفات المعدلة

- `StudyVault/AskModels.swift`

  - إضافة بروتوكولات Repository للخدمات.
  - إضافة خدمات محلية للتحقق، المسودات، الحفظ، التصويت، ملخص القرار، والتقييم الموزون.

- `StudyVault/ContentView.swift`
  - دعم حفظ المقارنات محليًا.
  - نقل منطق الصفحة الرئيسية والبحث والتصويت والحفظ إلى `HomeViewModel`.
  - نقل منطق نموذج إنشاء المقارنة والتحقق وحفظ المسودة إلى `CreateComparisonViewModel`.
  - تحسين شاشة إنشاء المقارنة بالتحقق العربي، الوسوم، الإعدادات، حفظ المسودة، واستعادة المسودة.
  - تحسين بطاقة ملخص القرار لاستخدام خدمة مستقلة.
  - إضافة زر حفظ في شاشة التفاصيل.

- `StudyVault.xcodeproj/project.pbxproj`
  - إضافة `ViewModels.swift` إلى Target الرئيسي حتى يدخل في البناء.

- `README.md`
  - تحديث وصف الميزات الحالية.
  - توضيح حدود النسخة المحلية.
  - توثيق الميزات التي تحتاج Backend فعلي.

## الميزات المنفذة

- نماذج بيانات MVP للمقارنات والخيارات والتصويت والأسباب والتعليقات.
- تصنيفات عربية موسعة مع أيقونات SF Symbols.
- تحقق من إنشاء المقارنة:
  - عنوان غير فارغ.
  - خياران على الأقل.
  - منع أسماء الخيارات المكررة.
  - منع الخيارات الفارغة.
  - رسائل خطأ عربية.
- حفظ واستعادة مسودة محليًا.
- حفظ وإلغاء حفظ المقارنات محليًا.
- ملخص قرار مستقل يوضح:
  - الخيار المتصدر.
  - مستوى الثقة.
  - الفارق بين الخيارات.
  - تحذير عند قلة الأصوات أو تقارب النتيجة.
- بروتوكولات واضحة لطبقة البيانات والتصويت والتعليقات والمصادقة.
- خدمات محلية قابلة للاستبدال عند إضافة Backend.
- `HomeViewModel` مبني بـObservation لإدارة حالة الصفحة الرئيسية والتصويت والحفظ والبحث.
- `CreateComparisonViewModel` مبني بـObservation لإدارة حالة إنشاء المقارنة، التحقق، المسودات، وإنتاج نموذج السؤال النهائي.
- تحديث README وخطة التنفيذ.

## الميزات المؤجلة

هذه الميزات تحتاج Backend أو إعداد خارجي قبل تنفيذها بشكل حقيقي:

- التصويت الجماعي المتزامن بين المستخدمين.
- رفع صور الخيارات.
- مزامنة الحفظ والمسودات بين الأجهزة.
- التعليقات المتقدمة والردود.
- الإشعارات الفعلية.
- الإبلاغ والإشراف الحقيقي.
- منع التلاعب من جهة الخادم.
- حسابات المستخدمين الكاملة وحذف الحساب.
- الذكاء الاصطناعي الحقيقي وجلب البيانات من الإنترنت.

## نتائج Build

تم تشغيل البناء التالي:

```bash
xcodebuild -project StudyVaultApp/StudyVault.xcodeproj -scheme StudyVault -destination generic/platform=iOS -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

النتيجة: نجح البناء وانتهى بـ:

```text
** BUILD SUCCEEDED **
```

تمت إعادة تشغيل البناء بعد إضافة `ViewModels.swift` وربطه بالـTarget، ثم بعد نقل منطق إنشاء المقارنة إلى `CreateComparisonViewModel`، ونجح البناء مرة أخرى.

## نتائج الاختبارات

لا يوجد Test Target مضاف حاليًا في مشروع Xcode، لذلك لم يتم تشغيل XCTest فعلي. لم أضف Target جديدًا للاختبارات لأن ذلك يتطلب تعديلًا أكبر في ملف المشروع وقد يؤثر على إعدادات الرفع الحالية. تم التحقق العملي عبر Build كامل للهدف الأساسي.

## إعدادات Backend المطلوبة

لتحويل النسخة المحلية إلى منصة عامة حقيقية، يلزم Backend يوفر:

- جدول/مجموعة للمقارنات.
- جدول/مجموعة للخيارات.
- جدول/مجموعة للتصويتات مع منع التكرار.
- جدول/مجموعة لأسباب التصويت.
- جدول/مجموعة للتعليقات.
- مصادقة مستخدمين.
- تخزين صور.
- إشعارات.
- قواعد أمان وصلاحيات.
- Rate limiting ومراقبة إساءة الاستخدام.

## خطوات يدوية مطلوبة

- مراجعة التحذيرات الخاصة بالأصول في Xcode، خصوصًا أيقونات غير مخصصة داخل `AppIcon` و`HeroEmblem`.
- إذا أردت نشر نسخة جديدة، ارفع Build جديد بإصدار أعلى من آخر نسخة مقبولة في App Store Connect.
- عند إضافة Backend، استبدل الخدمات المحلية بتنفيذ فعلي للبروتوكولات الموجودة.

## القيود الحالية

- التصويت والحفظ والمسودات محلية على الجهاز.
- لا توجد مزامنة فعلية بين مستخدمين.
- لا يوجد رفع صور فعلي.
- لا توجد اختبارات XCTest مهيأة في المشروع الحالي.
- بعض إعدادات App Store Connect لا يمكن التحقق منها من الكود وحده.

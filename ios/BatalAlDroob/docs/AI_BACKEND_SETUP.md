# إعداد خادم الذكاء الاصطناعي لبطل الدروب

هذا الخادم هو الطبقة الآمنة بين تطبيق بطل الدروب ومزود الذكاء الاصطناعي. لا يوضع مفتاح OpenAI داخل تطبيق iOS أبدًا.

## المتغيرات المطلوبة

أنشئ ملف `ios/BatalAlDroob/.env.local` على جهاز الخادم فقط، بناءً على `.env.example`:

| المتغير | الغرض |
|---|---|
| `OPENAI_API_KEY` | مفتاح OpenAI ويجب أن يبقى في الخادم فقط |
| `BATAL_AI_CLIENT_TOKEN` | رمز عميل للتطبيق يستخدم كطبقة تحقق قبل قبول الطلبات |
| `AI_MODEL` | نموذج الذكاء المستخدم، والقيمة الافتراضية `gpt-4.1-mini` |
| `PORT` | منفذ التشغيل المحلي، والقيمة الافتراضية `8787` |

## تشغيل الخادم محليًا

```bash
cd ios/BatalAlDroob/ai-backend
npm test
npm start
```

فحص الصحة:

```bash
curl http://127.0.0.1:8787/health
```

## ربط تطبيق iOS

يقرأ التطبيق القيمتين التاليتين من إعدادات البناء:

| Build Setting | مثال |
|---|---|
| `AIAssistantBaseURL` | `https://api.batalaldroob.com` |
| `AIAssistantClientToken` | نفس قيمة `BATAL_AI_CLIENT_TOKEN` في الخادم |

إذا كانت القيم غير موجودة أو بقيت كمتغيرات غير مستبدلة، يعمل التطبيق تلقائيًا في الوضع المحلي ولا يرسل بيانات خارج الجهاز.

## حماية الخصوصية

- لا يرسل التطبيق مفتاح OpenAI.
- لا يرسل الخادم كلمات المرور أو الأسرار أو VIN بشكل صريح.
- أرقام القطع المقفلة تبقى مقنعة ولا يرسل الرقم الكامل إلا إذا كان السجل مفتوحًا.
- `store:false` مستخدمة في طلبات OpenAI حتى لا يطلب الخادم تخزين المحادثة لدى المزود.
- الخادم يفرض حدًا لحجم الطلب، وعدد القطع المرسلة، ومعدل الطلبات.

## حدود الإصدار الحالي

رمز `AIAssistantClientToken` ليس بديلًا عن منظومة تحقق كاملة؛ هو طبقة حماية أولية. قبل الإنتاج الواسع يوصى بإضافة App Attest أو DeviceCheck، ومراقبة سجلات آمنة، وسياسات Abuse أقوى على الاستضافة.

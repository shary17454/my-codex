# تقرير إصلاحات الدرب - الإصدار 1.9.1 Build 77

## النطاق

تم العمل على تطبيق `الدرب` فقط داخل مشروع `DesertTrail`، دون تعديل Bundle ID أو فريق التوقيع أو الصلاحيات.

## الإصلاحات المنفذة

- توحيد رقم البناء على `77` في المشروع وسكربت Xcode Cloud.
- تحسين البوصلة بحيث تبقى علامات الاتجاه ثابتة ويتحرك سهم الاتجاه فقط حسب قراءة الجهاز.
- تفعيل زر SOS في لوحة القيادة وربطه بشاشة الاستغاثة بدل كونه زرًا بصريًا فقط.
- تحسين لوحة القيادة لإظهار قيم حقيقية أو `--` عند عدم توفر بيانات GPS بدل أرقام ثابتة مضللة.
- تحسين أزرار الخريطة أسفل الشاشة لتقليل تداخل النصوص وزيادة قابلية الضغط.
- تحسين شاشة إضافة موقع بإضافة زر إرسال واضح داخل النموذج وطلب تحديث الموقع عند استخدام الموقع الحالي.
- إصلاح إنشاء الرحلة الجديدة بحيث يمكن الحفظ حتى لو لم يكتب المستخدم اسمًا، مع استخدام اسم افتراضي مناسب.
- إضافة حفظ محلي للرحلات والمواقع المخفية وحالة المشاركة واللغة والرحلة المختارة عبر `UserDefaults`.
- تحسين شاشة الخرائط دون إنترنت بإضافة بحث ومناطق إضافية وحفظ أسماء الخرائط دون تكرار التاريخ داخل العنوان.
- تحديث قائمة تحقق الإصدار لتشير إلى Build `77`.

## التحقق المنفذ

- `git diff --check`: ناجح.
- Debug build باستخدام Xcode الافتراضي: ناجح.
- Release build باستخدام Xcode `26.6 (17F113)` و iPhoneOS SDK `26.5`: ناجح.
- فحص Xcode Cloud guard باستخدام Xcode `26.6`: ناجح.
- فحص Info.plist داخل التطبيق المبني: الاسم `الدرب`، الإصدار `1.9.1`، البناء `77`، Bundle ID `com.codex.DesertTrail`.
- تثبيت نسخة Release على Simulator وإطلاقها: ناجح.

## قيود التحقق

- لا يوجد Test action مهيأ في Scheme، لذلك لم تعمل `xcodebuild test`.
- GPS والبوصلة والطقس تحتاج اختبارًا نهائيًا على جهاز فعلي لأن Simulator لا يعطي دقة حساسات ميدانية مماثلة.
- الرفع إلى App Store Connect لم يتم من هذه الخطوة؛ المشروع جاهز لبناء Xcode Cloud جديد بعد رفع هذا التعديل إلى الفرع الصحيح.

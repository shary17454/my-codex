# تقرير تحديث تطبيق البيد

تاريخ التقرير: 2026-07-15

## الحالة السابقة

- المشروع تطبيق iOS أصلي باسم `DesertTrail` داخل مستودع يحتوي مشاريع أخرى.
- التطبيق يستخدم SwiftUI وMapKit وCoreLocation وCloudKit.
- الإصدار قبل التعديل كان `1.8` ورقم البناء `60`.
- أعلى بناء ظاهر في App Store Connect للإصدار 1.8 كان `66`، لذلك تم تجهيز بناء أعلى.
- البناء قبل التعديل نجح على iPhone Simulator، بينما الاختبارات غير مفعلة في Scheme.

## المعمارية والتقنيات

- الواجهة: SwiftUI.
- الخرائط: MapKit مع طبقات PDF/Tiles اختيارية.
- الموقع والبوصلة: CoreLocation داخل `LocationManager`.
- الطقس وجودة الهواء: `WeatherService` عبر REST مع كاش مؤقت.
- التخزين والمزامنة: UserDefaults وCloudKit حسب الميزة.
- اللغات: العربية والإنجليزية، مع وجود خيارات الفرنسية والإسبانية والصينية في محدد اللغة.

## التغييرات المنفذة

- رفع الإصدار إلى `1.9.1`.
- رفع رقم البناء إلى `68`.
- إصلاح إنشاء رحلة جديدة وربطه بقائمة رحلات قابلة للتعديل بدل الاعتماد على ثلاث رحلات ثابتة فقط.
- إضافة حفظ الرحلات والمشاركين وتحديث وجهة الرحلة من المواقع المقترحة.
- توسيع قاعدة المواقع المحلية المعتمدة للبحث والاختيار داخل نموذج إضافة موقع.
- إصلاح نموذج إضافة موقع بحيث لا يتم تعطيل زر الإرسال عند إدخال بيانات صحيحة.
- إصلاح شاشة خرائط بلا إنترنت وإضافة عدة مناطق تحميل بدل تكرار وادي حنيفة.
- تحسين البوصلة لتدور حلقة الاتجاهات حول سهم ثابت يشير للشمال، مع طلب الموقع عند الحاجة.
- ربط أزرار لوحة القيادة بواجهات فعلية لإضافة موقع، اختيار وجهة، وتشغيل/إيقاف الملاحة.
- تحسين تحديث بيانات الطقس وجودة الهواء وإظهار رسالة حالة للمستخدم.
- تحسين إعادة تمركز MapKit عند تغيير المنطقة أو الطبقة.
- تحسين زر اختيار اللغة في شريط التطبيق لتقليل التداخل.
- تحسين أزرار وضع القيادة لتصبح أكثر وضوحًا وقابلة للضغط مع عنوان مرئي لكل زر.
- تحسين أزرار خريطة الرحلة والطبقات لتقليل قص النصوص داخل الإطارات.
- تحسين أزرار مصادر الخرائط البرية وتصفية PDF/WMS/WMTS حتى تتسع النصوص بشكل أفضل.
- تحسين إعادة رسم طبقة Tiles عند تغيير الشفافية.
- تحديث ملاحظات الإصدار داخل `AppStore/ReleaseNotes.md`.
- تحديث قائمة الإرسال داخل `AppStore/SubmissionChecklist.md`.

## الخصوصية والأمان

- لم يتم تغيير Bundle ID أو Team ID أو Signing أو Entitlements.
- لم تتم إضافة صلاحيات جديدة.
- تم الإبقاء على `PrivacyInfo.xcprivacy` كما هو لأن التغييرات الحالية لا تضيف جمع بيانات جديدًا.
- لا توجد أسرار تمت إضافتها أو طباعتها.

## الأداء وتجربة المستخدم

- التغييرات منخفضة المخاطر ومركزة على تقليل تداخل النصوص وتحسين قابلية الضغط.
- لم يتم تغيير تدفقات الملاحة أو التخزين أو CloudKit.
- لم يتم تغيير الحد الأدنى لنظام iOS.

## التحقق

- Debug build نجح.
- Release build نجح.
- `git diff --check` نجح.
- فحص conflict markers لم يجد تعارضات.
- أمر الاختبارات فشل لأن Scheme `DesertTrail` غير مهيأ لاختبارات، وهذا ليس ناتجًا عن التعديلات.

## قيود لم يتم تجاوزها

- لم يتم رفع التطبيق أو إرساله إلى App Store لأن إعداد المهمة الحالي هو `PREPARE_ONLY`.
- لم يتم تنفيذ فحص Accessibility Inspector أو Instruments يدويًا داخل واجهة macOS.
- لم يتم تشغيل UI Tests لأن المشروع لا يحتوي إعداد اختبار مفعّل في Scheme.

## توصيات لاحقة

- تفعيل Unit/UI Test targets في Scheme.
- اختبار GPS والبوصلة والطقس على جهاز iPhone فعلي لأن Simulator لا يعطي حساسات ميدانية دقيقة.
- مراجعة App Store Privacy Labels يدويًا قبل كل إرسال.
- تنفيذ فحص Accessibility Inspector للشاشات الرئيسية.

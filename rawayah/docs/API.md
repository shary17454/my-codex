# API

Base URL:
- محليًا: `http://localhost:4000/api`

## المسارات الأساسية
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/refresh`
- `GET /users/me`
- `PUT /users/me`
- `GET /home`
- `GET /poems`
- `GET /poems/:id`
- `POST /poems`
- `POST /poems/:id/submit`
- `GET /search?query=`
- `POST /comments`, `/favorites`, `/questions`, `/reports`

يوفر Swagger على: `/api/docs`.
